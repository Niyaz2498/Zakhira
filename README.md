# Zakhira

This is my personal task manager custom fitted based on my current Necessity.

A pnpm monorepo: a Cloudflare Workers backend, a Tauri desktop app, and an Expo
Android app, sharing types and an API client through `packages/core`.

```
backend/          Cloudflare Workers + Hono + Drizzle + D1
apps/desktop/     Tauri v2 + React + Vite
apps/mobile/      Expo + Expo Router (Android, sideload only)
packages/core/    Shared types, API client, domain rules
packages/ui/      Shared design tokens
```

See [ARCHITECTURE.md](ARCHITECTURE.md) for how it all fits together.

## Prerequisites

- Node 20+ and `pnpm`
- `wrangler` (installed as a backend dev dependency)
- `eas-cli` for mobile builds — `npm install -g eas-cli`
- Rust toolchain for desktop builds — https://rustup.rs

```bash
pnpm install
```

## Local development

Run the backend first; both apps talk to it.

**Backend** — needs `backend/.dev.vars` (gitignored) with:

```
ADMIN_SECRET=test_secret
JWT_SECRET=dev_jwt_secret_change_in_prod
```

```bash
cd backend
pnpm db:migrate:local     # apply migrations to the local D1
pnpm dev                  # wrangler dev
```

Note the port wrangler prints — it may not be 8787 if that port is taken.

**Create a user.** There is no sign-up; users exist only when an admin creates
them. The admin endpoint authenticates with `ADMIN_SECRET` as a bearer token:

```bash
curl -X POST http://localhost:8788/admin/users \
  -H "Authorization: Bearer test_secret" \
  -H "Content-Type: application/json" \
  -d '{"username": "niyaz", "password": "test123"}'
```

**Desktop**

```bash
cd apps/desktop
pnpm tauri:dev            # native window
pnpm dev                  # or just the web UI on :1420
```

**Mobile**

```bash
cd apps/mobile
pnpm start
```

### Pointing the apps at a local backend

Both apps default to the production URL. To override in development, create a
`.env.development.local` (gitignored) in the app directory:

```bash
# apps/desktop/.env.development.local
VITE_API_URL=http://localhost:8788

# apps/mobile/.env.development.local
EXPO_PUBLIC_API_URL=http://192.168.1.6:8788    # LAN IP, not localhost
```

Mobile must use your machine's LAN IP — a device or emulator can't reach
`localhost`.

> **Use `.env.development.local`, never `.env.local`.** Vite and Expo both load
> `.env.local` in *every* mode, including production builds, so a dev URL in
> that file gets compiled into your release artifacts. Only `.env.[mode].local`
> is scoped to a single mode.

## Production builds

### Backend

```bash
cd backend
wrangler secret put JWT_SECRET      # once, generate with: openssl rand -hex 32
wrangler secret put ADMIN_SECRET    # once
pnpm db:migrate:remote
pnpm deploy
```

Secrets set via `wrangler secret put` apply to the deployed Worker only. Local
dev reads `backend/.dev.vars` instead, so both need setting.

### Desktop

```bash
cd apps/desktop
pnpm tauri:build
```

Verify the right URL was compiled in before shipping:

```bash
grep -c "localhost" dist/assets/*.js          # want 0
grep -c "workers.dev" dist/assets/*.js        # want 1 or more
```

To build against a different backend without editing files, pass it inline —
inline vars take precedence over `.env` files:

```bash
VITE_API_URL=https://your-backend.workers.dev pnpm tauri:build
```

### Mobile (sideload APK)

Android only, distributed by sideloading — there is no Play Store variant.
The `preview` profile in `eas.json` pins `EXPO_PUBLIC_API_URL` to the public
backend, so the APK always points at production regardless of local env files.

```bash
cd apps/mobile
eas login                                          # once
eas build --profile preview --platform android
```

EAS returns a download link when the build finishes. Install the APK on your
device and sign in with the credentials created by the admin endpoint.

`apps/mobile/android/` is generated by `expo prebuild` and is gitignored on
purpose — EAS regenerates it from `app.json`, which stays the source of truth
for the package name, icons, splash, and config plugins.

## Notes

- **Application ID is `site.niyaz.zakhira`.** Don't change it — doing so orphans
  everything stored in SecureStore on existing installs.
- **Auth is username + password.** Login returns a JWT (1 year TTL) held in
  SecureStore on mobile and localStorage on desktop. There is no revocation
  list; rotating `JWT_SECRET` invalidates every issued token.
- **Timers live on the server** in `tasks.timer_started_at`, so a timer started
  on one device shows as running on the other.
- After installing a desktop build that previously pointed somewhere else, hit
  **Sign out** once. The app persists the API URL at login and prefers the
  stored value on later launches.
